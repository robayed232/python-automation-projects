# File Organizer

A simple Python GUI application that automatically organizes files into folders based on their file types.

## Features
- Select a folder using a graphical interface
- Organize images, documents, videos, audio, archives, and other files
- Simple interface built with Python Tkinter

## Downloads
Download the ready-to-use Windows and Linux builds from the [Releases](../../releases) page.

## Run from source
Requires Python and Tkinter.

```bash
python gui_organizer.py
```

## Safety
Test the application on a sample folder before using it on important files. The application moves files rather than copying them.
